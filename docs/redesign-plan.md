# skyernovie.cn 风格重构计划（Minecraft UP 主主题）

> 状态：草案，等你拍板方向后再动手。本文只描述"要改成什么样、怎么改、怎么验收"，没有改动任何站点文件。

## 一、现状诊断（有据可查）

| 维度 | 现状 | 问题 |
| --- | --- | --- |
| 配色 | 靛紫 `#6366f1 → #a78bfa` 渐变，深色底 `slate` 系 | 通用科技风，和"Minecraft 模组实况"没有关系 |
| 面板 | 同时并存 `glass-effect`(5 处)、`liquid-glass`(15 处)、`liquid-glass-light`(9 处) 三套玻璃 | 同层级卡片看起来不是一家人 |
| 圆角 | `rounded-lg` 3 处 / `rounded-xl` 16 / `rounded-2xl` 13 / `rounded-3xl` 1 / `rounded-full` 18 | 没有圆角阶梯，纯靠手感 |
| 按钮 | `.btn-primary`(1)、`.btn-outline`(2)、`.btn-glass`(1) + 各种临时拼的 `<a class="...">` | 主次不分，社区卡里的"加入群聊"是硬编码蓝色 |
| 硬编码颜色 | `#FB7299` ×4、`teal-500`、`bg-blue-500` 等散落在 JSX | 换主题要满文件找 |
| 字体 | Geist + Geist Mono + 系统中文 | 数字没有"Minecraft 计数器"的质感 |
| 键盘可用 | 全站 `focus-visible` 0 处、`aria-expanded` 0 处、`Escape/keydown` 0 处 | 键盘用户看不见焦点，弹层关不掉 |
| 导航 | `linkClass(active)` 已有但 `active` 从未计算 | 滚动时不知道自己在哪一节 |
| 群号 | 群号只是文字 `<span>` | 访客要手动选中复制 |
| 单文件 | `src/pages/TzXyz.jsx` 560 行，页面逻辑/数据/样式混在一起 | 改一处要通读全部 |

## 二、三条风格路线（选一条再动手）

| | A. 方块夜行（推荐） | B. 材质包点缀 | C. 像素复古 |
| --- | --- | --- | --- |
| 一句话 | 保留现在的玻璃夜景，把强调色换成草绿/钻石青，MC 元素做在装饰层 | 骨架完全不动，只在首屏/加载/成就提示上加入 MC 彩蛋 | 整套 MC 原生 GUI：像素字、凹凸按钮、硬阴影 |
| 改动量 | 中（约 60% 样式 + 组件重构） | 小（约 15%） | 大（几乎重写） |
| 风险 | 低，可视反馈快 | 极低，但"主题感"弱 | 高，**上次就是这条路线的简化版，被否了** |
| 适合 | 想要"是我的世界 UP 主"，但仍要好看、耐看 | 只想换个味道 | 想要强 IP 感、接受不精致 |

**建议 A**，并把 C 的像素元素只用在彩蛋位（404、加载、成就提示），不要铺满全站。

| `border` | `rgba(255,255,255,.10)` | `rgba(15,23,42,.08)` | 描边 |

| `muted` | `#94a6c0` | `#5b6b85` | 次要文字 |

### 字号 / 圆角 / 阴影 / 动效

- 字阶：`12 / 14 / 16 / 20 / 24 / 32 / 44`，正文 16，卡片标题 16–20，区块标题 28–32
- 圆角阶梯固定 4 档：`6 / 10 / 14 / 18`，卡片 18、按钮 10、标签 6、头像与徽章 full
- 阴影：常态 `0 2px 8px rgba(2,6,23,.18)`；hover `0 16px 40px rgba(2,6,23,.28)` + `translateY(-4px)`
- 动效：hover 160ms、进场 300ms、区块揭示 600ms，统一 `cubic-bezier(.4,0,.2,1)`；`prefers-reduced-motion` 全部降级

### 字体

不引入像素字体（常用中文像素字库 2–4MB，首屏代价太大）。改用"数字/英文用 Geist Mono + 少量 letter-spacing"来模拟 MC 计数器，中文仍走 Geist + 系统字。

## 四、"Minecraft 感"具体落在哪（避免又土又花）

1. **首屏地平线**：hero 底部一条像素阶梯草方块（纯 CSS，8px 高，两色），上方夜空渐隐 + 现有粒子
2. **像素图标**：自制 16×16 内联 SVG（草方块、钻石、工作台、告示牌、命令方块、红石），替代现在的 emoji 图标
3. **分割线**：4px 方块 + 4px 间隔的像素虚线，替换现在的渐变细线
4. **成就提示（toast）**：复制群号、TD 里程碑时，用"成就达成"样式的弹条（金色边框 + 物品图标）
5. **加载页**：草方块逐个下落堆叠
6. **404**：掉进虚空的小人剪影 + "你已掉出世界边界"
7. **视频卡角标**：`EP.1` 位置用像素小标签，播放量前加 ▶ 像素三角

## 五、组件级改造

### 全局壳层
- `src/App.jsx`：抽出 `<SkipLink />`（跳转到 #main），补 `id="main"`
- `Navbar`：滚动区块高亮（IntersectionObserver）+ 顶部 2px 阅读进度条；移动端菜单补 `aria-expanded`、ESC 关闭、点遮罩关闭、打开时锁滚动
- `Footer`：统一为一行品牌 + 三个外链（B站/QQ群/邮件），高度收敛
- `ScrollToTopFab`：外面加一圈环形进度；移动端不与底部内容重叠（安全区）

### Hero
- 结构：左头像（144px，圆角 18，外圈 2px 草绿描边）/ 右侧名字 + 一句话 + 状态芯片（"直播中 / 未开播"，静态字段，后续可接接口）
- CTA 分层：B站主页 = 主按钮（草绿实心），直播间 = 次按钮（描边），QQ群/抖音 = 图标按钮（ghost）
- TD 按钮改造成"成就计数器"样式：数字用 Geist Mono，点击有 +1 浮动动画 + 里程碑 toast

### 统计卡（4 张）
- 统一为：图标（像素 SVG，32px）+ 数值（mono，32px）+ 标签（12px muted）
- 数值进场滚动动画（`requestAnimationFrame`，尊重 reduced-motion 时直接显示）
- 数据全部来自 `src/data/stats.json`（粉丝数已接入），系列名/更新频率也收进同一份数据文件

### 精选视频
- 固定 16:9 缩略图，`loading="lazy"` + 显式宽高防抖
- hover：缩略图 1.04 放大 + 中央播放按钮淡入 + 标题变草绿
- 右下角播放量徽章（`▶ 16.0万`），左上角 `EP.1`/`合集` 像素标签
- 标题最多两行（`line-clamp-2`），描述三行截断
- "查看更多视频"从整卡链接改成卡片底部的一个按钮，避免误触

### 整合包资源导航
- 从"三个按钮"升级成三张平台卡：平台图标 + 名称 + 一句话说明 + 外跳箭头
- 卡片整体可点，`rel="noopener noreferrer"`，hover 抬升

### 粉丝社区
- 群号右侧加"复制"按钮（Clipboard API，失败降级 `execCommand`），复制成功弹成就 toast
- "已满员"用灰化 + 图标，不再是纯文字标签
- 统一按钮：入群 = 主按钮，官方频道 = 次按钮
- QQ 频道卡与群卡统一高度、统一图标容器

### 与我联系
- 两块卡片统一：图标 + 标题 + 副标题 + 右箭头，整体可点
- 若后续加邮箱，用同样的卡片样式

### 杂项页面
- `Loading`：草方块下落动画（reduced-motion 时静态）
- `NotFound`：虚空彩蛋 + "回主页"主按钮

## 六、交互与可用性清单

| 场景 | 现在 | 改成 |
| --- | --- | --- |
| 键盘 Tab | 无焦点样式 | 全站统一 `:focus-visible` 草绿描边 2px + 2px offset |
| 移动端菜单 | 只能点按钮关闭 | + ESC 关闭、点遮罩关闭、打开时锁 body 滚动 |
| 设置弹层 | 无 aria、无 ESC | 同上 + `role="dialog"` + 焦点回到触发按钮 |
| 锚点导航 | 无当前位置提示 | 滚动时高亮当前区块，点击后有 100px 偏移（已存在）|
| 群号 | 手动复制 | 一键复制 + toast |
| 外链 | 直接跳走 | 统一图标提示"在新窗口打开" |
| 回顶按钮 | 300px 后出现 | 400px 后出现 + 环形进度 |
| 图片 | 无尺寸 | 显式宽高 + lazy，避免 CLS |
| 动效偏好 | 部分支持 | 全量尊重，canvas 粒子在移动端降级为静态渐变 |

## 八、验收标准

- [ ] 深/浅两套主题下，正文对比度 ≥ 4.5:1，次要文字 ≥ 3:1

- [ ] 键盘可完成：开菜单 → 选区块 → 关菜单 → 复制群号 → 回顶

- [ ] 首屏 LCP < 2.5s（本地 preview），总 JS 不增加超过 30KB
- [ ] 所有外链 `target="_blank" rel="noopener noreferrer"`
- [ ] `npm run build` 通过，产物无多余 chunk
